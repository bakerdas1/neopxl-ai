API Keys

How to use

Pass your API key in the X-API-Key header for all requests. No login needed — the key identifies you.

Submit a document (async — returns job ID, then poll status):

curl -X POST 'https://pars2.neopxl.online/api/extract?mode=async' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -F 'file=@"/path/to/document.pdf"' \
  -F 'template_id=np_001'
curl -X POST 'https://pars2.neopxl.online/api/extract?mode=async' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -F 'file=@"/path/to/document.pdf"' \
  -F 'schema=[{"name":"invoiceNumber","type":"string","description":"Invoice number"}]' \
  -F 'filter={"keepIf":{"items":{"description":"landing"}}}'

Check job status:

curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://pars2.neopxl.online/api/result/THE_JOB_ID'

Get extraction data for a job:

curl -H 'X-API-Key: YOUR_API_KEY' \
  'https://pars2.neopxl.online/api/tasks/THE_JOB_ID/data'
