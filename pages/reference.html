API Reference

Manage API Keys

Overview

Programmatic access to the extraction, schema generation and classification engines. All endpoints return JSON.

Base URL
https://pars2.neopxl.online
Authentication
X-API-Key: YOUR_API_KEY
Alternative auth
Authorization: Bearer <JWT>

Create an API key on the API Keys page and send it in the X-API-Key header on every request. No login session needed — the key identifies your account.

Extraction
POST/extract

Submit a document for extraction. The job runs in the background and returns immediately with a jobId. Poll GET /api/tasks/:id for status and results.

FieldTypeRequiredDescription
filefileyesDocument to extract (multipart/form-data)
templatestringnoTemplate id or name (e.g. np_001 or "Landing Invoices")
schemastring (JSON)noArray of field definitions, e.g. [{"name":"invoiceNumber","type":"string","description":"..."}]
filterstring (JSON)noRow filter: {"keepIf":["landing","take off"],"dropIf":["noise","infrastructure"]} — words are matched (case-insensitive, hyphen-normalised) against each row's description + charges_type
pagesstringnoPage range to extract, e.g. 1-9, 3, or 1,3,5-7 (default: all pages)
curl -X POST 'https://pars2.neopxl.online/extract' \ -H 'X-API-Key: YOUR_API_KEY' \ -F 'file=@"/path/to/document.pdf"' \ -F 'template=np_001'
Response
{
  "jobId": "c368fc4c6f44e76e",
  "status": "processing",
  "estimatedTime": "~2 min",
  "resultUrl": "/api/result/c368fc4c6f44e76e"
}
POST/api/extract

Same as /extract but supports both sync and async modes. Append ?mode=async to return a jobId immediately; omit it to wait for the full result synchronously (can be slow for large documents). Accepts the same fields (file, template, schema, filter, pages).

curl -X POST 'https://pars2.neopxl.online/api/extract?mode=async' \ -H 'X-API-Key: YOUR_API_KEY' \ -F 'file=@"/path/to/document.pdf"' \ -F 'schema=[{"name":"invoiceNumber","type":"string","description":"Invoice number"}]'

Supported file types: pdf, png, jpg, jpeg, txt, docx, html, xlsx, xls, csv

POST/api/classify

Analyse a document and return the best-matching template based on keyword matching plus AI classification.

curl -X POST 'https://pars2.neopxl.online/api/classify' \ -H 'X-API-Key: YOUR_API_KEY' \ -F 'file=@"/path/to/document.pdf"'
Response
{
  "success": true,
  "template_id": "np_001",
  "template_name": "Landing Invoices",
  "confidence": "high",
  "method": "keywords",
  "keywordHits": 4,
  "matchedKeywords": ["landing", "parking", "take off"]
}
Tasks
GET/api/tasks

List extraction tasks, newest first. Supports pagination.

QueryTypeDescription
limitintPage size (default all)
offsetintOffset for pagination (default 0)
curl -H 'X-API-Key: YOUR_API_KEY' \ 'https://pars2.neopxl.online/api/tasks?limit=25&offset=0'
Response
{
  "jobs": [
    { "id": "c368fc4c6f44e76e", "fileName": "invoice.pdf",
      "status": "done", "pages": 3, "timing": { "total": 48231 },
      "cost": { "total": 0.0045 }, "geminiCalls": 3, "userName": "Jane Doe" }
  ],
  "total": 104,
  "schemaCount": 13,
  "hasMore": true
}
GET/api/tasks/:id

Get a single task with full status, timing, cost and token usage. Use this to poll a job after submitting.

curl -H 'X-API-Key: YOUR_API_KEY' \ 'https://pars2.neopxl.online/api/tasks/c368fc4c6f44e76e'
GET/api/tasks/:id/data

Get the extracted JSON data for a completed task.

curl -H 'X-API-Key: YOUR_API_KEY' \ 'https://pars2.neopxl.online/api/tasks/c368fc4c6f44e76e/data'
GET/api/tasks/:id/csv

Export the extracted line items for a completed task as a CSV-ready payload. Returns { fileName, charges, details, rowCount }.

curl -H 'X-API-Key: YOUR_API_KEY' \ 'https://pars2.neopxl.online/api/tasks/c368fc4c6f44e76e/csv'
GET/api/tasks/:id/file

Download the original uploaded source file for a task. Add ?name=<stored_name> to pick a specific stored file; otherwise the PDF (or first file) is returned.

curl -H 'X-API-Key: YOUR_API_KEY' \ -o invoice.pdf \ 'https://pars2.neopxl.online/api/tasks/c368fc4c6f44e76e/file'
POST/api/tasks/:id/rerun

Re-run an extraction using the same stored file, template or schema. Returns a new jobId.

curl -X POST 'https://pars2.neopxl.online/api/tasks/c368fc4c6f44e76e/rerun' \ -H 'X-API-Key: YOUR_API_KEY'
DELETE/api/tasks/:id

Delete a task and its stored files permanently.

curl -X DELETE 'https://pars2.neopxl.online/api/tasks/c368fc4c6f44e76e' \ -H 'X-API-Key: YOUR_API_KEY'
Schema Generation
POST/api/schema/generate

Generate an extraction schema from one or more sample documents (up to 10 files). Runs in the background — poll GET /api/schema/result/:id.

FieldTypeRequiredDescription
filefileyesSample document(s). Repeat the field for multiple files
instructionsstringnoExtra guidance for the schema model
modelstringnoModel override (default gemini-2.5-flash)
curl -X POST 'https://pars2.neopxl.online/api/schema/generate' \ -H 'X-API-Key: YOUR_API_KEY' \ -F 'file=@"/path/to/sample1.pdf"' \ -F 'file=@"/path/to/sample2.pdf"' \ -F 'instructions=Focus on landing and parking fee line items'
Response
{
  "jobId": "3f4a2c9b81d0e5aa",
  "status": "processing",
  "estimatedTime": "~1 min",
  "resultUrl": "/api/schema/result/3f4a2c9b81d0e5aa"
}

Templates
GET/api/templates

List all extraction templates.

curl -H 'X-API-Key: YOUR_API_KEY' \ 'https://pars2.neopxl.online/api/templates'
POST/api/templates

Create a template. Body is JSON with name, schema (JSON string of field definitions), optional filter, keywords (comma-separated, used for classification), domain (e.g. aviation — selects the domain profile for prompts, charge-type aliases and field vocabulary), dateFormat/dateInputFormat, and verifyCoverage.

curl -X POST 'https://pars2.neopxl.online/api/templates' \ -H 'X-API-Key: YOUR_API_KEY' \ -H 'Content-Type: application/json' \ -d '{ "name": "Landing Invoices", "schema": "[{\"name\":\"invoiceNumber\",\"type\":\"string\",\"description\":\"Invoice number\"}]", "filter": "{\"keepIf\":[\"landing\"],\"dropIf\":[\"noise\"]}", "keywords": "landing, parking, take off", "domain": "aviation" }'
PUTDELETE/api/templates/:id

Update or delete a template by id. PUT accepts the same JSON body as creation; DELETE removes it.

Account & Stats
GET/api/keys

List API keys for the current user.

POST/api/keys

Create a new API key. Body: {"name": "Postman"}. The full key is returned once.

Response
{
  "id": "a1b2c3d4",
  "name": "Postman",
  "key": "npk_4f8a...YOUR_KEY_ONLY_SHOWN_ONCE"
}
DELETE/api/keys/:id

Revoke an API key. It stops working immediately.

GET/api/me

Return the authenticated user profile.

GET/api/stats

Dashboard statistics: total jobs, successful/failed counts, total cost and Gemini calls.

GET/api/stats/templates

Per-template extraction counts and costs.

Response
[
  { "name": "Landing Invoices", "count": 76, "cost": 4.4536 },
  { "name": "Raw Markdown", "count": 1, "cost": 0 }
]

Error responses

All endpoints return 400 for invalid requests, 401 for missing/invalid authentication, 404 for unknown resources, and 500 for server errors.

{ "error": "Unauthorized — missing valid authentication" }
